# Uso de la API

La API de FactuIO permite integrar la funcionalidad de facturación verificada en cualquier sistema o aplicación. Está diseñada siguiendo los principios REST y utiliza JSON para el intercambio de datos.

<Callout kind="success" title="✅ API RESTful">

- Autenticación mediante API Keys
- Respuestas en formato JSON
- Códigos HTTP estándar
- Documentación OpenAPI/Swagger disponible

</Callout>

---

## URL Base

| Entorno | URL Base |
|---------|----------|
| Producción | `https://api.factuo.io/v1` |
| Sandbox/Pruebas | `https://api-sandbox.factuo.io/v1` |

---

## Autenticación

Todas las peticiones deben incluir la API key en el header `Authorization`:

```bash
curl -H "Authorization: Bearer factuio_sk_live_..." \
     https://api.factuo.io/v1/invoices
```

### Formatos de API Key

| Tipo | Prefijo | Uso |
|------|---------|-----|
| Tenant Live | `factuio_tk_live_` | Administración de tenant |
| Tenant Test | `factuio_tk_test_` | Pruebas de administración |
| Signer Live | `factuio_sk_live_` | Operaciones de facturación |
| Signer Test | `factuio_sk_test_` | Pruebas de facturación |

    "customer": {
      "name": "Cliente Ejemplo S.A.",
      "nif": "A87654321",
      "address": "Avenida Diagonal 456",
      "postal_code": "08006",
      "city": "Barcelona",
      "province": "Barcelona",
      "country": "ES"
    },
    "items": [
      {
        "description": "Servicios de desarrollo software",
        "quantity": 10,
        "unit_price": 150.00,
        "discount": 0,
        "vat_rate": 21.0

<Endpoint method="POST" path="/api/invoices/batch-submit" />

Crear y enviar múltiples facturas en una sola petición.

**Request:**
```json
{
  "invoices": [
    { /* factura 1 */ },
    { /* factura 2 */ }
  ],
  "submit": true
}
```

**Límites:**
- Máximo 100 facturas por batch
- Tamaño máximo del body: 10MB

### Gestión de Signers (Tenant)

<Endpoint method="POST" path="/api/signers" />

Crear un nuevo signer.

```json
{
  "email": "contable@empresa.com",
  "first_name": "María",
  "last_name": "López García",
  "phone": "+34612345678",
  "role": "ACCOUNTANT"
}
```

---

<Endpoint method="GET" path="/api/signers" />

Listar todos los signers del tenant.

**Query params:**
- `status` - Filtrar por estado (ACTIVE, PENDING, SUSPENDED)
- `page` - Número de página (default: 0)
- `size` - Tamaño de página (default: 20, max: 100)

---

<Endpoint method="GET" path="/api/signers/{signer-id}" />

Obtener detalles de un signer específico.

### API Keys (Tenant)

<Endpoint method="POST" path="/api/signers/{signer-id}/api-keys" />

Crear una nueva API key para un signer.

```json
{
  "name": "Producción ERP SAP",
  "expires_in_days": 90
}
```

**Response:**
```json
{
  "id": "api-key-uuid",
  "name": "Producción ERP SAP",
  "fullKey": "factuio_sk_live_abc123...xyz789",
  "keyPrefix": "factuio_sk_live_abc123",
  "created_at": "2024-01-15T10:00:00Z",
  "expires_at": "2024-04-15T10:00:00Z"
}
```

<Callout kind="warning" title="⚠️ Importante">
El campo `fullKey` solo se muestra una vez en la creación. Almacénalo de forma segura.
</Callout>

---

<Endpoint method="DELETE" path="/api/signers/{signer-id}/api-keys/{key-id}" />

Revocar una API key.

## Códigos de Respuesta

| Código | Significado | Descripción |
|--------|-------------|-------------|
| `200` | OK | Petición exitosa |
| `201` | Created | Recurso creado exitosamente |
| `204` | No Content | Petición exitosa, sin contenido |
| `400` | Bad Request | Datos de entrada inválidos |
| `401` | Unauthorized | API key inválida o faltante |
| `403` | Forbidden | Sin permisos para la operación |
| `404` | Not Found | Recurso no encontrado |
| `409` | Conflict | Conflicto de estado (ej: factura ya firmada) |
| `422` | Unprocessable | Validación de negocio fallida |
| `429` | Too Many Requests | Límite de rate excedido |
| `500` | Server Error | Error interno del servidor |

## Manejo de Errores

Todos los errores siguen el mismo formato:

```json
{
  "error": {
    "code": "INVALID_INVOICE_DATA",
    "message": "Los datos de la factura no son válidos",
    "details": [
      {
        "field": "customer.nif",
        "message": "El NIF no tiene formato válido"
      },
      {
        "field": "items[0].unit_price",
        "message": "El precio debe ser mayor que 0"
      }
    ],
    "request_id": "req_abc123xyz",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}
```

### Códigos de Error Comunes

| Código | Descripción | Solución |
|--------|-------------|----------|
| `INVALID_NIF` | NIF/CIF inválido | Verificar formato correcto |
| `DUPLICATE_INVOICE_NUMBER` | Número de factura duplicado | Usar numeración única |
| `COMPANY_NOT_FOUND` | Empresa no encontrada | Verificar company_id |
| `SIGNER_NOT_ACTIVE` | Signer no activo | Activar cuenta del signer |
| `QUOTA_EXCEEDED` | Cuota excedida | Contactar soporte para ampliar |
| `AEAT_UNAVAILABLE` | AEAT no disponible | Reintentar más tarde |

## Webhooks

### Configuración

```json
{
  "url": "https://miempresa.com/webhooks/factuio",
  "events": ["invoice.signed", "invoice.submitted"],
  "secret": "whsec_mi_secreto",
  "active": true
}
```

### Verificación de Firma

```python
import hmac
import hashlib

def verify_webhook(payload, signature, secret):
    expected = hmac.new(
        secret.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)
```

## Ejemplos de Integración

### cURL

```bash
# Crear factura
curl -X POST https://api.factuo.io/v1/invoices/submit \
  -H "Authorization: Bearer factuio_sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "invoice": {

      },
      "items": [{
        "description": "Servicio",
        "quantity": 1,
        "unit_price": 100.00,
        "vat_rate": 21
      }]
    },
    "submit": true
  }'
```

### JavaScript/Node.js

```javascript
const response = await fetch('https://api.factuo.io/v1/invoices/submit', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + API_KEY,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    invoice: {
      company_id: companyId,
      invoice_number: 'FAC-2024-001',

      },

        quantity: 1,
        unit_price: 1000,
        vat_rate: 21
      }]
    },
    submit: true
  })
});

const result = await response.json();
console.log('Factura creada:', result.invoice.id);
```

### Python

```python
import requests

headers = {
    'Authorization': 'Bearer factuio_sk_live_...',
    'Content-Type': 'application/json'
}

data = {
    'invoice': {
        'company_id': 'uuid-empresa',
        'invoice_number': 'FAC-001',
        'customer': {
            'name': 'Cliente S.A.',
            'nif': 'A12345678'
        },
        'items': [{
            'description': 'Servicio',
            'quantity': 1,
            'unit_price': 100.00,
            'vat_rate': 21
        }]
    },
    'submit': True
}

response = requests.post(
    'https://api.factuo.io/v1/invoices/submit',
    headers=headers,
    json=data
)

result = response.json()
print(f"Factura creada: {result['invoice']['id']}")
```
