# Rol Signer

El **Signer** es el usuario autorizado para crear, firmar y gestionar facturas en nombre de una empresa. Representa típicamente a un contable, administrativo o cualquier persona con capacidad legal para firmar documentos fiscales.

<Callout kind="info" title="Definición">
Un Signer es un firmante autorizado que puede crear facturas, aplicarles la firma electrónica requerida por Verifactu y gestionar el ciclo de vida de las mismas.
</Callout>

---

## Características del Rol Signer

| Aspecto | Descripción |
|---------|-------------|
| **Creación** | Creado por el Tenant (administrador) |
| **Autenticación** | API key proporcionada por el Tenant |
| **Alcance** | Limitado a las empresas asignadas |
| **Operaciones** | CRUD de facturas + firma |

---

## Activación de Cuenta

Cuando el Tenant crea un Signer, este recibe un email de activación:

### Proceso de Activación

1. **Recibe email** con enlace de activación
2. **Establece contraseña** segura
3. **Configura 2FA** (recomendado)
4. **Obtiene API key** del Tenant para integraciones

<Callout kind="warning" title="⚠️ Importante">
El enlace de activación expira en 24 horas. Si caduca, el Tenant debe reenviar la invitación.
</Callout>

## Estados de una Factura

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   DRAFT     │───▶│  SIGNED     │───▶│  SUBMITTED  │───▶│  CONFIRMED  │
│  (Borrador) │    │  (Firmada)  │    │  (Enviada)  │    │ (Confirmada)│
└─────────────┘    └─────────────┘    └──────┬──────┘    └─────────────┘
                                             │
                                             ▼
                                      ┌─────────────┐
                                      │    ERROR    │
                                      │   (Error)   │
                                      └─────────────┘
```

| Estado | Descripción |
|--------|-------------|
| `DRAFT` | Factura creada pero no firmada |
| `SIGNED` | Firmada digitalmente, lista para envío |
| `SUBMITTED` | Enviada a la AEAT, esperando confirmación |
| `CONFIRMED` | Confirmada por la AEAT |
| `ERROR` | Error en el proceso, requiere revisión |

## Firma de Facturas

### Tipos de Firma

| Tipo | Descripción | Uso |
|------|-------------|-----|
| **Factura completa** | Firma con certificado digital del signatario | Facturas normales |
| **Sello de tiempo** | Marca temporal adicional | Alto valor |
| **Firma delegada** | A través de representante | Casos especiales |

### Proceso de Firma

1. El Signer crea la factura con `submit: false`
2. Revisa los datos de la factura
3. Aplica la firma digital (automática con API key)
4. Opcionalmente, envía a la AEAT

```json
// Crear sin enviar
{
  "invoice": { /* datos */ },
  "submit": false  // Solo crea, no firma ni envía
}
```

## API Key del Signer

El Signer utiliza la API key proporcionada por el Tenant:

```bash
# Ejemplo de autenticación
curl -X POST https://api.factuo.io/api/invoices/submit \
  -H "Authorization: Bearer factuio_sk_live_51H8m...a3B9" \
  -H "Content-Type: application/json" \
  -d '{"invoice": {...}}'
```

<Callout kind="danger" title="🔐 Seguridad">

- Nunca compartas tu API key
- No la incluyas en código frontend
- Úsala solo en servidores backend seguros
- Solicita una nueva si sospechas compromiso

</Callout>

## Preguntas Frecuentes

**¿Puedo firmar facturas de varias empresas?**
Sí, si el Tenant te ha asignado permisos sobre ellas.

**¿Qué pasa si la AEAT rechaza una factura?**
Recibirás una notificación con el código de error. Puedes corregir y reenviar.

**¿Puedo modificar una factura ya firmada?**
No, las facturas firmadas son inmutables. Debes crear una factura rectificativa.

**¿Cómo obtengo el QR de verificación?**
Se genera automáticamente y viene en la respuesta de la API (`qr_code`).
